# The November 2026 reset: "calculators that show the work"

calculator.rest becomes one focused site: calculators for school and everyday maths that solve the reader's exact
numbers step by step, the way a teacher would. It launches small (23 calculators, 30 indexable URLs) at the URLs
Google already tested, and then it is left alone. The model is calcultaxesquebec.ca, which grew through Google's
November update with a working tool on every page, the answer and the number first, short pages, a small launch
and slow edits.

## What changed technically

- **Template** (`build.mjs`, `src/render.js`): H1 = the tool's name; one answer sentence; the calculator with its
  default example solved in the server HTML; "Show the work" steps rendered inside the live `<output>` so they
  update with the reader's numbers and also work without JavaScript; Key facts; worked example; 2–3 search-worded
  variant H2s; common mistakes; 3–5 related; 3–5 FAQs. Schema: WebApplication + FAQPage + BreadcrumbList.
- **Hubs** (`src/hubs.mjs`): 4 hubs at pre-pivot hub URLs Google had already shown (`/everyday-calculators`
  #9.6, `/math-calculators` #5.8, `/science-calculators` #4, `/school-calculators`), each a one-line description
  and a table of its calculators with their worked answers.
- **Homepage**: the percentage calculator, solved, above the fold, then the hubs. Title "calculator.rest: Maths
  Calculators That Show the Work". (Body copy says "math": 72% of impressions were US.)
- **About / Methodology** rewritten to the new scope: how steps are produced and checked, the rounding policy,
  what the build refuses to publish, how to report an error. No credential claims. Dot stays.
- **Sources**: each cited URL was opened (HTTP 200) and states the formula: OpenStax (College Algebra 2e, College
  Physics 2e, Chemistry 2e, Introductory Statistics 2e), Wolfram MathWorld, NIST SP 811 for units. Everyday
  arithmetic pages (tip, split bill, party food, time) cite nothing rather than something decorative.
- **One host**: apex only, www → apex 308, canonical = live URL on every page (build-checked).
- **Sitemap**: one `sitemap.xml` with only the indexable URLs and each page's real `updated` date.
- **IndexNow**: `scripts/indexnow-release.txt` lists the 27 restored URLs (23 calculators + 4 hubs). The workflow
  submits it after the production deploy **only when that file changed in the deployed commit**, so the merge
  submits once and later deploys submit nothing. (Before this change, any deploy that touched `build.mjs` would
  have resubmitted every URL.) The script refuses any URL that is not in the sitemap.
- **Build checks that fail the build** (all new except the meta checks): ≤ 45 indexable URLs; ≤ 5 hubs, none
  with < 2 calculators; title ≤ 60 chars with a number; one answer sentence with a number; ≥ 3 server-rendered
  steps starting "Formula" and ending "Answer"; Key facts with formula/vars/rounding; 2–3 variants; 2–5 mistakes;
  3–5 FAQs; 3–5 related; 600–1,100 words; ≤ 30% 5-gram overlap between any two calculators; no digits in
  indexable slugs, no duplicate `compute()`, no names that differ only by numbers; lastmod not all identical
  except on the 2026-11-26 release date; no future dates; canonical on the apex host.
